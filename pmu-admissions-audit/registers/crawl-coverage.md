# Crawl Coverage Register — PMU Admissions

**Verification date:** 2026-09-27 (Asia/Riyadh)
**How pages were read:** through the user's own Opera browser (Browser Connector), using the accessibility-tree text of each page plus viewport screenshots. The audit container itself could not reach `pmu.edu.sa` because its egress proxy blocked the domain. Extra URLs were found with web search, but search results only contribute a URL and title. They are **not** treated as evidence of page content.
**Access state:** "Loaded" means the page rendered real content in the browser. The Browser Connector does not report raw HTTP status codes, so none are claimed here. Where the address bar showed a different final URL, that redirect is recorded.

Legend. Scope: **Core** = sits directly on the applicant's path to a decision. **Support** = needed to complete that path. **Adjacent** = linked from admissions pages but not about admission. Generation: **Current**, **Legacy** or **Unclear**.
